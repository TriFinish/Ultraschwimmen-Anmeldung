# Eigene Symbole

Hier liegen SVG-Dateien, die als `<Icon name="dateiname" />` verfügbar sein
sollen — ohne Iconify-Präfix.

Aktuell ist das Verzeichnis leer: Alle Symbole kommen aus Lucide über Iconify
(siehe `astro.config.mjs`). Es existiert trotzdem, weil astro-icon sonst bei
jedem Build `Failed to load icons from "src/icons"` warnt — und eine Warnung,
die immer steht, bringt niemanden mehr dazu, hinzusehen.
